## About

I'm Ridoy, a backend-focused developer who enjoys turning complex requirements into understandable APIs, data models, and application flows. My physics background shapes how I approach engineering: start with the fundamentals, question assumptions, and work through the problem.

I build with TypeScript, Node.js, and the React ecosystem. My current focus is **system design**: understanding the trade-offs behind reliable services, beyond getting a feature to work. I'm also learning **Rust**, starting with ownership, borrowing, and error handling.

## Current focus

| Direction | What I'm exploring |
| :--- | :--- |
| **System design** | Requirements, capacity estimates, service boundaries, and architectural trade-offs |
| **Data & scale** | Database modeling, indexing, caching, replication, and consistency |
| **Reliable services** | Queues, retries, idempotency, observability, and failure recovery |
| **Rust** | Ownership and borrowing, lifetimes, traits, error handling, and concurrency fundamentals |

> My learning approach: understand the problem, sketch the design, build a small version, and examine where it breaks.
